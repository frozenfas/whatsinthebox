Photo scale card

A printable ruler to put behind an object before photographing it, so size can be read precisely from the photo instead of guessed - especially useful for coins, where size often tells two similar ones apart. Print once, keep it, reuse it. When your printer's dialog opens, choose Actual size (not "Fit to page") or the ruler will be wrong.

Connected services

Everything this app talks to outside your phone, and why.

Anthropic
api.anthropic.com		Identifies each photo. Your key, sent only when you capture something.
Microsoft OneDrive
login.microsoftonline.com, graph.microsoft.com		Syncs the catalogue between phones, only if you connect it above. What it stores is encrypted first.
Open Library
openlibrary.org		Looks up author/year for anything identified as a book. No account, runs automatically, fails silently if nothing matches.
Numista
api.numista.com		Looks up coin details, only if you've added a key above. Your key, sent only for items identified as coins.
Danger zone

Permanently erases every house, location, and item in this browser's storage. Does not touch your saved API keys, sync passphrase, or OneDrive connection. A catalogue + photos backup downloads automatically first, and you'll be asked to confirm twice.
